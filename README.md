# E-commerce PHP

Progetto universitario di sviluppo di un'applicazione web e-commerce.

## Tecnologie utilizzate

- PHP
- HTML
- CSS
- MySQL
- SQL

## Funzionalità

- Visualizzazione dei prodotti
- Gestione dei prodotti tramite database
- Interazione con il database
- Struttura delle pagine web tramite PHP

## Database

Il progetto utilizza un database MySQL contenente i dati relativi ai prodotti e alle funzionalità dell'applicazione.

## Obiettivo

Il progetto è stato realizzato per mettere in pratica competenze di sviluppo web, programmazione PHP e gestione di database relazionali.
